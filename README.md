# Excel 数据合并脚本

把多个 Excel 合并成一张总表。三种模式，一条命令搞定。

两种用法共用同一套合并逻辑，结果完全一致：

* **桌面端**：双击 `启动桌面版.bat`（或打包出来的 `Excel合并工具.exe`），选文件夹、点按钮。
* **命令行**：`python3 merge_excel.py -i ./数据 -m concat`，适合写进批处理、定时任务。

## 环境要求

**Python 3.11 或更高版本**（pandas 3.0 的硬性要求）。先确认一下：

```bash
python3 --version
```

如果显示的不是 3.11+，或者运行时报 `SyntaxError`，说明你调用的是老版本解释器。
请改用 `python3`，或者直接双击 **`启动桌面版.bat`**（Windows，打开窗口）/
**`运行.command`**（macOS，文字问答）——它们会自动选对 Python，适合不习惯敲命令的情况。
打包成 exe 之后连 Python 都不用装，见 [桌面端](#桌面端不想敲命令)。

> 常见坑：macOS 上 `python` 和 `python3` 可能指向不同版本，装依赖用的 `pip`
> 和运行用的 `python` 也可能不是一个环境。用桌面端可以完全绕开这个问题。

## 安装依赖

```bash
pip install -r requirements.txt
```

只需一次。用到旧版 `.xls` 必须装 `xlrd`（已包含在依赖里）。

## 三种模式

| 模式 | 用途 | 什么时候用 |
|---|---|---|
| `concat` | 纵向拼接 | 几个文件表头一样，要把数据行上下堆起来（最常见） |
| `merge` | 横向合并 | 类似 VLOOKUP，按某个字段把另一个表的列拼过来 |
| `sheets` | 多工作表汇总 | 一个工作簿里有很多 sheet，或要把所有文件的所有 sheet 汇总 |

## 桌面端（不想敲命令）

Windows 双击 **`启动桌面版.bat`**，或者 `python3 gui.py`（macOS 的 `运行.command` 是纯文字问答版，
不需要图形界面也能用）。窗口从上到下就四块：

| 区域 | 对应的命令行参数 |
|---|---|
| 输入：选文件夹，或点「选几个文件…」直接挑文件 | `-i` / `--recursive` / `--pattern` / `-f` |
| 合并方式：三选一；选「横向合并」时才需要填关键列和连接方式 | `-m` / `-k` / `--how` / `--sheet` |
| 选项与输出 | `--keep-types` / `--no-source` / `-o` |
| 运行日志 | 终端里那些 `[信息] / [警告] / [错误]` 原样显示 |

跑完点「打开结果所在文件夹」直接跳到结果文件。界面只负责收集参数，
执行的是和命令行同一个 `run_merge()`，所以不存在"桌面端和命令行结果不一样"。

### 打包成免安装的 exe

要给没装 Python 的同事用，双击 **`打包_exe.bat`**（需要联网，只有这一步才需要 PyInstaller），
产物在 `dist` 文件夹里：

* `Excel合并工具.exe` —— 双击开窗口，不带黑色命令行窗口
* `merge_excel.exe` —— 命令行版，参数与 `python merge_excel.py` 完全一致，
  例如 `merge_excel.exe -i .\数据 -m concat`

exe 在哪个文件夹，默认就扫描那个文件夹、把结果写到它旁边的 `output`。

> 改 `启动桌面版.bat` / `打包_exe.bat` 时注意：这两个文件是 **ANSI/GBK** 编码保存的。
> 用编辑器另存成 UTF-8 之后，cmd 会把中文行从中间拆开执行，报一堆
> `xxx is not recognized as an internal or external command`。

## 快速开始

```bash
# 1. 纵向拼接：合并「数据」文件夹里所有 Excel，结果写到 ./output
python3 merge_excel.py -i ./数据 -m concat -o ./output

# 2. 横向合并：按「学号」把成绩表拼到名单上
python3 merge_excel.py -i ./数据 -m merge -k 学号

# 3. 多工作表汇总：递归扫描，把每个文件的每个 sheet 汇总成一张表
python3 merge_excel.py -i ./数据 -m sheets --recursive

# 4. 只合并指定的几个文件（指定后不再扫描目录）
python3 merge_excel.py -f 1月.xlsx 2月.xlsx 3月.xlsx
```

输出文件默认命名为 `合并结果_20261001_143000.xlsx`（带时间戳，不会覆盖旧结果），
放在 `-o` 指定的目录里。**脚本拒绝把结果写回任何一个输入文件。**

## 参数

### 输入

| 参数 | 默认 | 说明 |
|---|---|---|
| `-i, --input-dir` | 当前目录 | 要扫描的文件夹 |
| `-f, --files` | 无 | 直接指定文件，指定后不再扫描目录 |
| `--recursive` | 关 | 连子目录一起扫描 |
| `--pattern` | `*.xls*` | 文件过滤通配符 |
| `--sheet` | 第一个 | `concat`/`merge` 读哪个工作表，可写表名或序号 |

### 合并方式

| 参数 | 默认 | 说明 |
|---|---|---|
| `-m, --mode` | `concat` | `concat` / `merge` / `sheets` |
| `-k, --keys` | 无 | `merge` 的关键列，可多列：`-k 学号 姓名` |
| `--how` | `left` | 连接方式：`left`/`right`/`outer`/`inner` |
| `--keep-types` | 关 | 保留原始数据类型，见下方说明 |
| `--no-source` | 关 | 不加「来源文件 / 来源工作表」标记列 |

### 输出

| 参数 | 默认 | 说明 |
|---|---|---|
| `-o, --output-dir` | `./output` | 输出目录，自动创建 |
| `--output` | 无 | 直接指定输出文件路径，优先于 `-o` |
| `-v, --verbose` | 关 | 输出调试信息 |

### 运行方式

| 参数 | 说明 |
|---|---|
| `--gui` | 打开桌面端窗口（其他参数被忽略），等价于双击 `启动桌面版.bat` |

## 关于数据类型（重要）

**默认把单元格当文本读取**，这样身份证号、银行卡号、手机号、带前导零的编号
（如 `001`）不会被转成 `1.10101E+17` 之类 scientific notation，也不会丢掉前导零。

代价是数值列在 Excel 里也变成文本，不能直接求和（单元格左上角会显示绿色三角）。

如果你的表需要直接做数值计算，加 `--keep-types`：

```bash
python3 merge_excel.py -i ./数据 -m concat --keep-types
```

此时数值保持数字类型，但长数字串会被 Excel 转成科学计数法。
**简单判断：要保号选默认，要算数选 `--keep-types`。**

## 表头不一致怎么办

取所有文件列的**并集**，缺的列留空，并且明确告诉你哪些文件结构不一样：

```
[警告] 结构差异 3月.xlsx：缺少 2 列 -> ['备注', '城市']（将留空）
[信息] 说明：共 3 个来源的表头不一致，已取全部列的并集
```

不会静默丢数据。另外默认会在最前面加一列 `来源文件`，方便追溯每行来自哪个文件；
`sheets` 模式还会加 `来源工作表`。不想要就加 `--no-source`。

## 常见问题

**提示「文件已损坏，或只是改了扩展名的非 Excel 文件」**
文件内容不是真 Excel（比如直接把 `.txt` 改名成 `.xlsx`）。用 Excel 打开另存一次即可。

**提示「没有读取权限，或文件正被 Excel 占用」**
Excel 正开着这个文件，先关掉再跑。

**扫描结果里少了一个文件**
Excel 打开文件时生成的 `~$xxx.xlsx` 临时锁文件会被自动跳过，这是正常的。

**文件很多但只合并了一部分**
看输出末尾的汇总：`完成，但有 N 个文件读取失败`。失败的文件会逐个列出原因，
不会中断其他文件的合并。退出码为 1 表示有部分失败，2 表示整体没跑起来，0 表示全部成功。

**`.xlsb` 格式读不了**
需要额外装一个依赖：`pip install pyxlsb`，或先另存为 `.xlsx`。

## 退出码

| 码 | 含义 |
|---|---|
| 0 | 全部成功 |
| 1 | 部分文件读取失败，其余已合并 |
| 2 | 目录不存在、没找到 Excel、参数有误等，未产出结果 |
